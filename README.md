# Fortune's Atlas · sitio público

Web: **https://pedrocd.github.io/FE-WF-pages/**

Este repositorio personal de **PedroCD** contiene únicamente la web compilada: HTML, JavaScript, CSS e imágenes. El proyecto fuente `PedroCD/FE-WF` conserva su visibilidad privada y no se publica aquí. No hay relación con ninguna organización empresarial.

Guía no oficial de Fire Emblem: Fortune's Weave, centrada en el reparto y la consulta de regalos, con interfaz pública en español e inglés. La versión japonesa y la tier list están ocultas por ahora. El catálogo documenta 123 regalos; los nombres españoles sin confirmar llevan asterisco y no se inventan preferencias ausentes o contradictorias.

Los personajes elegidos y las cantidades válidas se recuerdan automáticamente en el mismo navegador, sin cuentas ni sincronización entre dispositivos. Los botones de vaciar están debajo de cada lista. «Restablecer todo» elimina también la selección guardada. Las listas mantienen el orden alfabético mientras no se pueda verificar la secuencia del juego.

Las actualizaciones de estos archivos en `main` se publican mediante GitHub Actions y GitHub Pages. No se necesitan secretos de cuentas externas, backend, base de datos ni servicios de pago.

Fire Emblem pertenece a Nintendo / Intelligent Systems. Las imágenes y las fuentes conservan sus derechos originales. Este repositorio no concede licencia de redistribución sobre recursos de terceros.
